### Projects

**Custom 3D Graphics Engine** — A rendering engine built from scratch featuring on-the-fly asset and shader loading, multiple lighting models, camera types, and procedural terrain generation.
`C++` `OpenGL` `GLSL`

**Fish Species Identification & Counting** — A computer vision system for identifying and counting fish species in photos and video using YOLOv11, with curated training datasets and tuned hyperparameters for species-level accuracy.
`Python` `YOLOv11` `PyTorch` `OpenCV`

**[Hobble](https://github.com/EthanKelly01/hobble)** — A toy programming language with a fully functional compiler. Implements data types, functions, loops, and conditions; loosely based on the GulfOfMexico joke spec.
`Kotlin` `ANTLR`

**[Driva](https://github.com/Ahad0926/Mobile-Project/)** — A cross-platform mobile app for tracking and comparing commute times across transport modes, similar to Strava.
`Flutter` `Dart` `Firebase` `Google Maps API` `SQLite`

**[PongWin](https://github.com/EthanKelly01/JavaFX-Game)** — An online multiplayer Pong variant with real-time game state synchronization and multiple independently-controlled application windows.
`Java` `JavaFX` `Multithreaded Networking`

**[File Storage Server](https://github.com/EthanKelly01/Server)** — A self-hosted offsite file storage system using raw Java socket programming, with a JavaFX client supporting messaging and file transfers of any type.
`Java` `Java Sockets` `JavaFX`
